**陕西信息大厦**（对照 xinxi_1 / xinxi_0 / xinxi_4crop）
- ✔ 圆柱玻璃塔身 + 两道白色石材端墙：从西南看端墙正好在左右两缘、顶端高出玻璃顶，与 xinxi_1 一致（旧模型是方塔 + 四棱锥 + 尖塔）。
- ✔ 退进玻璃圆筒 + 挑出的薄圆盘 + 两根桅杆（立在端墙顶）；屋面直升机坪；底部米色石材基座（窗洞）；北侧皇冠假日裙楼绿色屋面与“CROWNE PLAZA”屋面字（与卫星一致）。
- △ 玻璃颜色：本场景天空偏灰白，高反射玻璃（共享幕墙着色器金属度 0.72）映出的颜色比晴天照片浅；tint 从档案 `#23507e` 压到 `#153a63`、白带比例 0.28→0.2 后变化不大，端墙在强光下也偏白。照片是饱和深蓝——属于全局光照/天空问题，不在单栋 spec 里硬调。
- △ 档案文字说“外凸弧面（椭圆/透镜形平面感）”，实测 OSM 轮廓为正圆 + 端墙，按轮廓建（照片中“弧面”即圆柱面，两端的“平直端墙”即西北/东南两道墙）。
- ✘ 未建：西南面顶部的白色横带“T”形图案与中信徽标、竖向白色点线装饰；入口雨棚与柱廊。桅杆高低：照片间不一致，按等高处理。
