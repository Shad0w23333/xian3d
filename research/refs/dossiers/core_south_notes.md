## 2. 字段约定（在用户给定 schema 之外的补充）

- `footprint_size_m`：Overture 轮廓最小外接矩形 [长, 宽]（米）；`footprint_detail.long_axis_deg_from_east_ccw` 为长轴与正东夹角（逆时针为正，北向为正），可直接作 `rotation_deg` 参考。
- `world_xz`：用 `tools/geo.py project()` 算出的世界坐标（X 东、Z 南，原点钟楼）。
- `massing[].offset_m`：相对轮廓质心 [东, 北]；拿不准的一律 `null`。`size_m` 中为 `null` 的维度表示没有可靠来源（没用照片比例去“猜”）。
- 颜色 hex 为照片目视取色（受天气/白平衡影响，属“照片观察”级别，非材料色卡）。
- “照片计约 N 层”写在 `height_source`/`notes` 里并注明“非来源值”，没有写进 `floors`。
- `confidence`：high = 高度/年份有权威或多源一致 + 多张清晰照片；medium = 有主要事实与照片但缺高度或轮廓对位；low = 只有零星资料或照片不足/归属存疑。
