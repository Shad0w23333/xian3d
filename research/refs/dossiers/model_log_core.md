# 逐栋档案建模记录 · 明城墙以内 + 南门/南稍门一带（`src/arch/dossier-specs/core.js`）

范围：`core_south.json` 中位于明城墙以内（世界坐标 x −1985..2225、z −1830..848，城墙中线取自 `src/modules/citywall.js`）及永宁门外—南稍门一带的条目，
外加 `public.json` 中落在这一范围的条目（与 core_south 重复的只做一次）。陕西信息大厦、西安SKP 已由示范 `demo.js` 完成，未重复。

方法（每栋）：读档案 → 看照片（档案照片 `scratchpad/dossier_core_south/photos/*`；缺照片时用 Commons `Special:FilePath` 与 360 图片搜索补，
存 `scratchpad/core_agent/img/`）→ 卫星 + Overture 轮廓 + buildings.bin 高度叠图（`scratchpad/core_agent/sat/*.jpg`，自写 `site.py`）→ 写 spec。
高楼在 Esri z19 上屋面向东（略偏南）偏移约 0.37 m/每米楼高（由凯爱/工行大楼 83 m ↔ 约 31 m 位移、奥罗 74 m ↔ 约 27 m 位移互证），
塔楼一律落在轮廓（底座）上；无层数/高度出处的，按照片数层 × 合理层高，或用卫星倾斜位移 ÷ 0.37 反推，并在 spec `meta.notes` 写明。

建模库扩展（`src/arch/dossier-kit.js`，写入 `docs/DOSSIER_KIT.md` §3.4/§3.6）：
- 塔冠 `hip`（中式大屋顶：庑殿 / 歇山 / 攒尖，出檐、起翘、封檐板、正脊鸱吻/宝顶）、`eave`（沿轮廓一圈的斜坡披檐，重檐下檐/仿古檐口）、`slab`（挑檐平板，可夜间发光）；
- tower 体块上直接压中式屋顶时女儿墙默认压到 0.2 m；招牌 `vertical: true` 竖排字；
- `src/modules/dossier.js` 招牌图集 4096×1024 → 4096×2048、行高 150 → 110（各片区招牌合计上百条，原图集只装得下约 36 条）。
以上均向后兼容（旧 spec 不受影响）。
