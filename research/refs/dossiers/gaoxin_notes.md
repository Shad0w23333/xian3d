# 高新区逐栋档案：调研笔记（2026-09-28）

配套数据是 `gaoxin.json`，共 56 条，坐标为 WGS-84。照片、网页快照和中间脚本都放在会话临时目录 `…/scratchpad/dossier_gaoxin/`，没有进仓库。json 里 `photos[].file` 写的是这个临时目录的路径，`photos[].url` 是原始出处。

## 1. 来源与方法

| 来源 | 用途 | 说明 |
|---|---|---|
| CTBUH Skyscraper Center | 高度、层数、完工年、状态（完工/在建/停工）、坐标、部分照片 | 用的是网页自带的公开搜索索引，取回西安 122 条，其中高新范围 71 条。非会员只能看到建筑高度 |
| 腾讯新闻、搜狐、网易、澎湃、赢商、观点网等 | 高度口径、位置描述、进度、立面材料、施工/开业照片 | 主要靠地产媒体“地产房剑”2020–2023 年的锦业路系列 |
| 高楼迷论坛（gaoloumi.cc 西安版） | 规划公示里的高度和层数、2024–2026 年进度 | 游客看不到图片，只用了文字 |
| Wikimedia Commons | 实景照片 | API 被限流，改抓 HTML 搜索页和 960px 缩略图 |
| zh.wikipedia | 国瑞、绿地的基本数据 | — |
| `data-src/overture/building.parquet` | `overture_id`、轮廓尺寸 | 尺寸取最小外接矩形 [长, 宽]；角度的定义见 §2 |
| 仓库既有参考图 `research/refs/skyline/*.jpg` | 只用了 `yanchang.jpg` | 原始出处没有记录，已在条目里注明 |

- WebSearch 本次用了 33 次，WebFetch 没用，网页一律用 curl 抓取。
- 用 Esri 影像核对的叠图因为瓦片下载超时只做了一张（锦业路南区），那批影像的拍摄年份不明，只作参考。
- 颜色 hex 的来源分三种：注明“采样”的是从照片区域取中值；注明“目测”的是看照片估的；没有照片的一律填 null。所有颜色都受天气和反射影响。

## 2. 字段约定（在任务字段之外的说明）

- `massing[].offset_m` 为 [东, 北]，单位 m，以条目的 lon/lat 为原点；都市之门、中投、高新医院、体育之窗、有色、秦煤、会议中心二期几条的偏移由 Overture 质心或 CTBUH 点换算得到。
- `rotation_deg` 是长边相对正东的角度，逆时针为正（向北转），由 Overture 最小外接矩形算出；手填的 0 表示没有资料，按正南北布置。
- `height_m` 取“建筑/塔冠顶”口径。多个口径并存时全部写进 `height_source`，并说明取了哪一个。
- 世界坐标附在每条 `notes` 末尾，格式为“世界坐标≈(x, z)”，由 `tools/geo.py project()` 算出，X 向东、Z 向南。
- schema 里没有 status 字段，所以未建成或停工的项目在 `name` 里直接标“（在建）/（停工）”，并在 `massing.notes` 里写明现状。收录这些项目，是为了提醒模型不要按设计全高去建。
- `photos` 为对象数组 `{file, url, desc}`。

## 4. 查不到的关键字段

- **平面/体量**：以下几栋 Overture 没有轮廓，平面尺寸为 null：泰信、安达仕、D5、ICC 两栋、夏中心、有色、体育之窗 1 号楼、比亚迪、环球西安中心、秦煤。其中秦商 1 号楼的尺寸改用楼书标准层平面（52.65×34.3 m / 52.0×33.0 m）。延长石油只知道是“椭圆平面”，塔在 236 m 长的整体轮廓中具体在哪一段，没有数据。
- **高度**：以下各栋高度未查到——中投 A/B（只有 24/27 层）、全部商场（万达、T11、DT51、世纪金花、金鹰、中大、都荟茂、立丰城裙楼、益田假日里）、全部酒店、医院、笔克、奥体馆。体育之窗 2、3 号楼的高度同样没查到；landmarks2026 写的 188 m 找不到出处。高新国际商务中心的口径冲突太大（155/150/197/220 m），暂时留空。
- **塔冠高度**：多数楼查不到。能推算的有：国瑞 16 m（350−334）、ICC 13.2 m（163.1−149.9）、延长 22.15 m（217.6−195.45）、安达仕 22.7 m（247.4−224.7，设计值）、秦煤 A 20 m（设计值）。
- **夜景**：只有绿地中心（LED 媒体立面、竖向上照光束）和君悦（塔顶紫光）有依据，其余一律为 null。
- **没找到可用照片**：永利、体育之窗、禾盛京广、电信广场、高新国际商务中心、香格里拉、丽思卡尔顿、万达广场、奥体馆、医院。
- **未收录**（坐标或资料无法核实）：
  - 西安国际医学中心医院：西太路 777 号，53 万㎡，5037 床。Overture 和 place 里都没有可对应的轮廓或点。
  - 长安通讯产业园：没检索到。
  - 荣民高新壹号：1# 约 207 m，2# 158 m 为威斯汀，2024-08 封顶；坐标未查到。
  - 西安高新洲际酒店：团结南路商圈，具体位置未查到。
  - 西部国际广场：只知道名字。
  - 秦商 2 号楼“锦里”：100 m/31 层，没有坐标。
- **范围说明**：任务里写的“中央创新区 CCBD”对应不上。检索结果显示 CCBD 是曲江的“中央文化商务区”（西安万象城、生命之树，不在本档案范围）；高新区三期叫“中央创新区 CID”，其中 498 m 的“丝路国际金融中心”仍在规划。CID/丝路科学城一带本档案只收了西安大剧院、省图高新馆、会议中心和会议中心二期。

**位置与重复**

- **永利国际金融中心**：模型点 (−5812,7521) 实际是秦商 1 号楼所在地块。按地址（锦业一路与丈八一路西南角）、CTBUH 坐标和秦商楼书区位图，永利在锦业一路以南 (−5822,7648)，偏差约 127 m。OSM w1387164542 标注的“永利 212 m”轮廓大概率是错标。
- **秦商国际中心**：landmarks2026 (−5930,7497) 与 CTBUH 点 (−5803,7471) 相差约 130 m。按楼书，1 号楼在地块东侧，紧挨丈八一路西侧。
- **泰信大厦**：landmarks2026 多边形中心 (−5991,7633) 实为中投国际综合体质心。泰信应在中投与永利之间，CTBUH 点 (−5904,7654)。
- **ICC**：landmarks2026 有“西安ICC环贸中心 主塔”和“ICC环贸中心写字楼”两个 163 m 塔（相距 29 m），酒店楼也有两份（−6912,7454 与 −7024,7470），属于重复建模。
- **禾盛京广 A/B**：sky-data.js（OSM 位置）和 landmarks2026（synth 位置 (−5107,3282)/(−5177,3282)）各建了一份，应删掉 landmarks2026 那两条。
- **体育之窗 1 号楼**：CTBUH 点与模型 ty1 相差 49 m；Overture 的“2号楼”轮廓 (−5098,6202) 离模型 ty1 更近。三栋塔的对应关系需要影像核对。
- **延长石油**：模型把塔放在整体轮廓西段 (−5156,5971)，缺少依据，需影像核对。

**招牌**

- **中铁西安中心**：模型写“中国中铁”。CTBUH 2020 照片放大后，塔冠上是“**新华保险**”（新华保险购入该楼 21 层）。
- **延长石油**：模型写“延长石油”。仓库参考图 `research/refs/skyline/yanchang.jpg` 中与之形态吻合的塔楼（椭圆塔身、波浪顶）挂的是“**秦农银行**”；是否就是这栋楼还需核实。
- **陕西电信广场**：模型写“中国电信”，没找到照片证实。

**模型缺失（已建成）**

- 秦商 1 号楼（217 m，2025 年建成）、泰信（214 m，2024 年建成）：sky-data 里没有，只在 landmarks2026 中出现，且位置有误。
- 比亚迪研发中心（200 m，2025）：模型未建。
- 环球西安中心（180 m，2023 年封顶）、荣民科创园 1#（215 m，结构 2020 年封顶，CTBUH 状态 On Hold）：完工情况不明，模型未建。

**已拆或正在拆**

- 盛大时代广场（唐延路，原卜蜂莲花）：2025-04/05 高楼迷记录正在拆除，landmarks2026 仍按商场建模。
- 绿地笔克会展中心：规划拆除改建“绿地之樽”（380 m 等），截至 2025 年仍在。
