## 你的任务
逐张、逐区域地看你分到的截图，找出**所有**让人觉得“不真实、不像西安、做错了、做粗了”的地方。
要求是**把每一处毛病都列出来**，不是挑几个代表。同一张图里有五处问题就写五条；同一个问题在你这批里出现在多张图上，写一条并在 shot 里列出所有图。
看图方法：先整体看一遍，再分九宫格逐块放大看。放大用：

    cd MAIN && .venv-tools/bin/python -c "from PIL import Image; im=Image.open('shots/grid1/<id>.png'); im.crop((x0,y0,x1,y1)).resize(((x1-x0)*2,(y1-y0)*2)).save('<你的临时目录>/<id>_crop.png')"

然后用 Read 看裁出来的图（临时目录用你自己的，例如 /private/tmp/audit3_<批号>/）。

## 什么算问题（举例，不限于此）
- 渲染错误：黑块、纯色块、闪烁残影、整片发白/过曝、阴影错乱、面片缺失（看到楼内部）、z 冲突花纹；
- 几何错误：穿模（车穿树、树穿楼、楼压路、路面穿地形）、悬空（树、车、人、设施浮在空中）、陷地、比例怪（巨人、迷你车、窗户过大）；
- 位置错误：车停在人行道/绿化带/广场上、树种在车道上、人走在车道中间、设施挡路、路口斑马线位置不对；
- 缺失或空旷：真实西安这里该有的东西没有（成片楼、街道设施、行道树、店招、车流），或者大片空地铺满单调铺装/卫星图糊斑；
- 单调重复：同一栋楼/同一棵树/同一个招牌成片复制、立面平板网格、屋顶全一样；
- 颜色材质：颜色突兀、塑料感、影像里的楼影子和 3D 楼打架、影像带雪/带车等季节或时间矛盾；
- LOD 与远景：远处楼块突然变色/变形、远景与近景色调断层、地面贴图分辨率太低；
- 夜景：该亮的不亮（路灯、窗户、招牌）、不该亮的亮（悬空光球、整面过亮）、天空颜色异常；
- 数据错误：楼的位置或高度明显不对（对比你对西安的了解与影像）、道路走向不对、水面出现在不该有的地方。
不要报：机位本身构图不好（例如紧贴墙看不到东西）——这类写一条 category=机位，总负责人改机位；纯主观的审美偏好。

## 严重度
- P0：一眼就能看出的大错（黑块、悬空大件、整片空白或错位、挡住视线的错误物体、地标错误）；
- P1：稍微看一下就觉得不真实（比例、明显重复、缺少该有的东西、颜色突兀、明显 LOD 跳变、物体放错位置）；
- P2：细节可以更好。

## 输出
按你拿到的 schema 返回 findings 数组，每条：
- shot：截图 id，可以多个，逗号分隔；
- where：画面位置，用像素框 (x0,y0)-(x1,y1)，加你推测的大致经纬度；
- what：问题描述，要具体到让修复者不看图也知道是什么；
- severity：P0、P1、P2；
- category：渲染错误、穿模、悬空、位置错误、缺失空旷、单调重复、颜色材质、LOD远景、夜景、数据错误、比例、机位，选一个；
- module：按上表推测；
- evidence：你怎么确认的，比如放大裁图路径、和哪张图对比；
- fix_hint：你建议的修法。
另外给每张图打一个真实感分（1~10），返回 scores：[{shot, score, one_line}]。
所有文字用简体中文。
