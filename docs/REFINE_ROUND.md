# 精修轮通用说明（5 个精修代理共读）

你在西安 3D 城市模型工程（Three.js r186 + Vite）的一个**独立 git 工作树**里做精修。主仓库：/Users/xiaochoumao/Documents/github repo/xian3d（下称 MAIN）。基线提交 d4612d8。

## 背景
上一轮（十路修复）已把一眼可见的大错修完：全城 59 机位巡检 0 报错、60 fps。用户看了修前修后对比仍说：“还可以做得更好更精细，现在还不满意”。
本轮目标是**近看的精细度**：人眼高度（1.7 m）与低空（30~100 m）下，普通城区（不是已精建的地标）看起来要像真实的西安街道和小区，而不是“方盒子 + 卫星贴图”。

## 开工准备（必须先做）
在你的工作树根目录执行（这些目录不在 git 里）：
    ln -s "MAIN/node_modules" node_modules; ln -s "MAIN/tiles" tiles; ln -s "MAIN/data-src" data-src; ln -s "MAIN/.venv-tools" .venv-tools
（MAIN 换成上面的绝对路径，路径含空格要加引号。）然后读 HANDOFF.md 第 3 节（目录结构）与第 13 节（最近一轮）。
如果工作树不在 d4612d8，先 `git reset --hard d4612d8`（工作树是新建的，没有你的改动时才这样做）。

## 现状截图（先看）
- MAIN/shots/fine1/*.png：本轮新拍的 30 张精细机位（机位表 MAIN/tools/tour_fine.json）：18 条街道人行道人眼高度、8 个小区内部 40 m 低空、4 张夜景。
- MAIN/shots/tour2/*.png：全城 59 机位（机位表 tools/tour_spots.json）。
已看出的共性问题（总负责人）：通用建筑屋顶是大块马赛克噪点、几乎没有屋顶构件，高层住宅立面是平网格、没阳台、楼顶无收头；
小区内部只有卫星图（无园路、围墙大门、停车位、健身设施、自行车棚）；普通街道上没有路牌/信号灯/公交站/垃圾桶/座椅/共享单车（只有几个精建片区有）；
近处行人是方块大头、比例细长；车辆是简模；路中间出现莫名的斑马线、路口缺停止线/导向箭头。

## 截图与验证
    node tools/shot.mjs --w 1280 --h 720 --wait 200 --frames 60 --shot "online=0&ll=lon,lat,离地高,目标lon,目标lat,目标离地高&time=15|shots/refine_<任务>/x.png"
批量：node tools/tour.mjs --list tools/tour_fine.json --out shots/refine_<任务>/after [--only id1,id2]（一次加载连拍，快；工具内置 Vite 已关热更新，可以边改边拍）。
参数：view=1..0 预设视角；time=小时；modules=a,b 只加载；skip=a,b 跳过；q=0..3；labels=1 显示标注；一律加 online=0。
性能：node tools/perf.mjs --views 2,4,7（改前改后各一次）。**预算**：预设视角 2/4/7 的三角形各 ≤ +15%，draw call ≤ +60；
人眼高度机位帧率不能明显下降。近景细节务必按距离分块加载/LOD（相机附近 1~2 km 生成，远处不画或合批）。
本机同时有 5 个代理在跑浏览器，截图慢属正常；整幅纯白（GPU 上下文丢失）就重拍。截图用 Read 查看。
每项：先拍修前 → 做 → 同机位拍修后（存 shots/refine_<任务>/before、after）。moduleErrors 必须为空、无 pageerror、无 GL_INVALID 警告。
临时文件放你自己的目录（不要用会话共用的 scratchpad/base 之类的公共目录，其他代理也在用）。

## 真实感参考
西安普通城区：主干道人行道 5~8 m，花岗岩方砖 + 盲道，行道树国槐/法桐，树池；路口有信号灯杆（悬臂）、人行信号灯、蓝底白字路名牌（中英）、
交通标志；公交站有顶棚和站牌；人行道上有共享单车（美团黄、哈啰蓝、青桔绿）和电动车；小区是围合式（铁艺围栏或砖墙 + 门岗 + 道闸），
内部有环形车道、地面停车、宅前绿地、健身器材、儿童游乐、电动车棚、垃圾分类亭、单元门雨棚；老小区（1980~2000）6~7 层砖混板楼，
外挂空调、防盗窗、晾衣架，屋顶有太阳能热水器、水箱；新小区 18~33 层塔楼，楼顶有电梯机房与构架收头，立面有阳台和空调格栅。
可以 WebSearch/WebFetch 查资料（例如西安路名牌样式、公交站样式、小区围墙样式），在提交说明里注明出处。
